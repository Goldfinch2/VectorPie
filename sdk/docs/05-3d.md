# 05 — 3D: `vp_3d`

`#include <vectorpie/vp.h>` (`vp_3d.h`). `examples/models` shows all of it.

> Objects drawn **solid** hide their own back; one object hiding another
> comes next.

## The view

```c
vp3d_view view;
vp3d_view_init(&view, 60.0f);                       /* horizontal field of view, degrees */
vp3d_look_at(&view, eye, target, vp_v3(0, 1, 0));   /* or vp3d_set_pose(&view, pos, heading, pitch, roll) */
```

World units are the game's own. Camera space: +x right, +y up, +z forward.
This world is **left-handed** (seen from the default camera, +x is right and
+z away from you).
`near_z` (default 0.1): lines crossing it are cut there. `far_z` (default
10000): lines entirely beyond it are not drawn.

**The screen shape.** The monitor stretches the square 0..4095 board space to
4:3. `view.aspect` (4/3 by default; 3/4 for a vertical monitor) compensates,
so a circle in the world is round on the tube.

**Fog.** `fog_start`, `fog_end`, `fog_floor`: full brightness up to
`fog_start`, `fog_floor` (0..1) of it from `fog_end` on. `fog_end <=
fog_start` turns it off (the default). On a vector monitor brightness is the
one depth cue there is.

## Placements: `vp_xf`

A 3x3 matrix (row-major) plus a translation: `p' = m * p + t`.

```c
vp_xf place = vp_xf_mul2(vp_xf_translate(x, 0, z), vp_xf_rot_y(heading));  /* rotate, then move */
```

`vp_xf_identity`, `_translate`, `_scale`, `_rot_x/_y/_z` (radians),
`vp_xf_mul2(a, b)` (b first, then a), `vp_xf_inverse`, `vp_xf_point`,
`vp_xf_dir`. Vectors: `vp_v3`, `vp_v3_add/_sub/_scale/_dot/_cross/_length/_normalize`.

## Lines and points

```c
vp_color(d, 0, 140, 0);
vp3d_line(d, &view, vp_v3(-50, 0, z), vp_v3(50, 0, z));
float sx, sy;
if (vp3d_project(&view, world, &sx, &sy)) { /* sx, sy in board units */ }
```

Lines use the current color, dimmed by fog. `vp3d_project` places 2D things
(radar blips, labels) on 3D positions.

## Meshes

Built in code:

```c
vp3d_mesh *m;
vp3d_mesh_create(&m);
int a = vp3d_mesh_vertex(m, x, y, z);   /* ... more vertices */
int face[4] = { a, b, c, e };
vp3d_mesh_face(m, face, 4);             /* anticlockwise seen from outside */
vp3d_mesh_line(m, a, b);                /* a lone line, part of no face */
vp3d_mesh_finish(m);
```

Or from a **Wavefront OBJ** file (any 3D tool exports it):

```c
vp3d_obj_options opt = {0};
opt.center = 1;                         /* bounding-box center to the origin */
opt.scale = 0.01f;                      /* e.g. centimeters to meters */
opt.z_up = 0;                           /* 1 if the tool exports Z-up */
vp3d_mesh_load_obj(path, &opt, &m);
```

It reads vertices (`v`), faces (`f`, any size, every index form, negative
indices) and lines (`l`); texture coordinates, normals, groups and materials
are not needed and ignored. A bad file is refused with its name and line in
`vp_last_error()`.

OBJ files are right-handed (Blender and most tools), this world is
left-handed: the loader flips z, so a model looks as it was authored (text on
it reads the right way, a left-hand drive car stays left-hand drive).

`vp3d_mesh_finish` (and the loader) turns the faces into **unique edges** (an
edge shared by two faces is drawn once) and the edges into **strokes**: paths
that cover every edge once, as few as the shape allows. A cube has 12 edges
and 8 corners where 3 edges meet, so it takes 4 strokes; a pyramid's 8 edges
take 2.

`vp3d_mesh_vertex_count`, `_face_count`, `_edge_count`, `_stroke_count`,
`_radius` describe it.

## Drawing: solid or wireframe

```c
vp_color(d, 0, 255, 255);
vp3d_draw_mesh(d, &view, m, &place, VP3D_SOLID);        /* or VP3D_WIREFRAME */
```

* **Solid** draws the mesh as an object, the way a person would draw it: its
  **outline** (the silhouette, where a face turned to the camera meets one
  turned away) and its **sharp creases** (where two faces meet at a sharper
  angle than the mesh's crease angle). A smooth surface shows only its moving
  outline; a box shows its visible edges.
* **Wireframe** draws every edge, see-through (`vp3d_draw_mesh_wire` is the
  same).

Either way: each edge once, in as few strokes as the visible edges allow, in
the current color dimmed by fog. A mesh wholly behind the camera or beyond
`far_z` costs almost nothing.

**Crease angle** (`vp3d_mesh_set_crease`, or `crease_deg` when loading):
40 degrees by default. Lower keeps more edges (0: every edge between faces you
can see), higher keeps fewer (180: the outline alone).

**Faces** must all be wound the same way round, either way: the SDK works out
which side is outside. A shape with no inside (a flag, a sign) needs
`vp3d_mesh_set_two_sided(m, 1)`, or its faces vanish when seen from behind.
